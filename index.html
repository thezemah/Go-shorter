Why Go-shorter

Everything you need, nothing you don't

⚡

Instant navigation

Type go/name directly in the address bar — no search results, no redirects through a server.

🔒

100% local

All data lives in chrome.storage.local. Nothing ever leaves your machine.

✍️

On-the-fly capture

Visit an unknown go/link and the Add form opens pre-filled — capture new links without breaking your flow.

🗂️

Full management

Search, edit, delete, import and export all your shortlinks as JSON from the built-in Manage page.

🌗

Light & dark theme

Automatically follows your system preference via prefers-color-scheme.

🔗

Works with any search engine

Google, Bing, DuckDuckGo, Brave, Yahoo, Yandex, Baidu — any engine with a standard query parameter is supported.

🛡️

Your data stays on your device

Go-shorter makes zero network requests of its own. No analytics, no telemetry, no accounts. Use Export / Import in the Manage page to back up or transfer your links between devices.

Get started

Install in 3 steps

Download the extension

Grab Go-shorter.crx from the latest release.

Enable Developer mode

Open chrome://extensions and toggle Developer mode in the top-right corner.

Drag & drop

Drag the .crx file onto the extensions page. Click Add extension when prompted.

Start using go-links

Click the toolbar icon, add a shortlink, then type go/name in the address bar!
